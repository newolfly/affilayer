Tracking

Tracking

Every click gets a unique click ID that stays linked to its conversion. No black box: here is exactly what is recorded and how links work.

Tracking links

A tracking link has this format:

https://go.affilayer.com/c/{affiliate_code}/{offer_id}

When a visitor clicks it, the tracking server records the click and responds with a 302 redirect to the offer landing page, with the click ID appended as a query parameter:

https://offer-landing.example/?click_id=clk_01J…

If the offer does not exist, the link returns 404 {"error":"offer not found"}.

Optional parameters

ParameterWhat it does
sub1 … sub5Your own sub-parameters, stored with the click for your reporting. Only sub1 is also passed through to postbacks.
sourceTraffic source label, stored with the click.
deviceDevice hint, stored with the click.
countryCountry hint, used when the visitor's country cannot be detected.

SmartLink

One link for mixed or unsegmented traffic:

https://go.affilayer.com/s/{smartlink_code}

SmartLink picks one eligible offer for the visitor, deterministically, from their country and device (and the country, device and source query hints when given), then redirects with the same 302 and click_id behaviour. The rules are fixed and readable — SmartLink does not use AI optimisation and does not guarantee earnings. If no offer is eligible, it returns 404 {"error":"no eligible offer"}.

What every click records

FieldMeaning
click_idUnique ID for the click (for example clk_…). This is what conversions link back to.
affiliate_code, offer_idWhose link it is, and which offer it points to.
sub1 … sub5Your sub-parameters.
sourceTraffic source label.
referrerThe page the visitor came from, when the browser sends it.
ipVisitor IP, used for fraud signals and country detection.
user_agentVisitor browser / device string.
countryDetected country, or the country query hint.
deviceDevice hint.

Looking a click up

GET https://go.affilayer.com/api/clicks/{click_id} returns the click and its conversion, if one exists. Unknown IDs return 404 {"error":"click not found"}.

Stats

GET https://go.affilayer.com/api/stats returns server-side aggregates over recorded events only — clicks, conversions and revenue as recorded, never estimates.

Conversions are never trusted from the client side. A conversion only enters the system through a signed server-to-server call — see API — and is recorded as pending until a person reviews it.
